# React Router DOM --- Notes

## What is React Router DOM?

**React Router DOM** is a library used in React applications to create
**routing/navigation between different pages or components without
reloading the entire webpage**.

### Installation

``` bash
npm install react-router-dom
```

### Import

``` jsx
import {
  BrowserRouter,
  Routes,
  Route,
  Link
} from "react-router-dom";
```

------------------------------------------------------------------------

## 1. BrowserRouter

`BrowserRouter` is the **main container that enables routing** in a
React application.

``` jsx
<BrowserRouter>
  <App />
</BrowserRouter>
```

### Purpose

-   Enables routing.
-   Keeps the UI synchronized with the browser URL.
-   Usually wraps the application or the part of the app that needs
    routing.

**Remember:**

> `BrowserRouter` → **Enables routing**

------------------------------------------------------------------------

## 2. Routes

`Routes` is a container that holds multiple `Route` components.

``` jsx
<Routes>
  <Route path="/" element={<Home />} />
  <Route path="/about" element={<About />} />
</Routes>
```

### Purpose

-   Groups the application's routes.
-   React Router finds the route that matches the current URL.

**Remember:**

> `Routes` → **Contains routes**

------------------------------------------------------------------------

## 3. Route

`Route` defines **which component should be displayed for a particular
URL path**.

### Syntax

``` jsx
<Route path="/about" element={<About />} />
```

Here:

``` text
path="/about"        → URL
element={<About />}  → Component to display
```

### Example

``` jsx
<Route path="/" element={<Home />} />
<Route path="/about" element={<About />} />
<Route path="/contact" element={<Contact />} />
```

  URL          Component
  ------------ -----------
  `/`          Home
  `/about`     About
  `/contact`   Contact

**Remember:**

> `Route` → **URL → Component**

------------------------------------------------------------------------

## 4. Link

`Link` is used to **navigate between routes**.

``` jsx
<Link to="/about">About</Link>
```

### Example

``` jsx
<nav>
  <Link to="/">Home</Link>
  <Link to="/about">About</Link>
  <Link to="/contact">Contact</Link>
</nav>
```

When the user clicks **About**, React Router navigates to `/about` and
displays the component associated with that route.

**Remember:**

> `Link` → **Navigation**

------------------------------------------------------------------------

# Complete Example

``` jsx
import {
  BrowserRouter,
  Routes,
  Route,
  Link
} from "react-router-dom";

function Home() {
  return <h1>Home Page</h1>;
}

function About() {
  return <h1>About Page</h1>;
}

function Contact() {
  return <h1>Contact Page</h1>;
}

function App() {
  return (
    <BrowserRouter>

      <nav>
        <Link to="/">Home</Link>
        <Link to="/about">About</Link>
        <Link to="/contact">Contact</Link>
      </nav>

      <Routes>

        <Route path="/" element={<Home />} />

        <Route
          path="/about"
          element={<About />}
        />

        <Route
          path="/contact"
          element={<Contact />}
        />

      </Routes>

    </BrowserRouter>
  );
}

export default App;
```

------------------------------------------------------------------------

# How Routing Works

``` text
User clicks Link
       ↓
<Link to="/about">
       ↓
URL becomes /about
       ↓
Routes checks available Routes
       ↓
<Route path="/about">
       ↓
<About /> is displayed
```

# Therefore,
  `BrowserRouter`   Enables routing
  `Routes`          Contains routes
  `Route`           Maps URL to component
  `Link`            Navigates between routes

## One-Line Memory Trick

**BrowserRouter → Routes → Route → Link**

> **BrowserRouter enables routing, Routes contains routes, Route decides
> what to display, and Link provides navigation.**
