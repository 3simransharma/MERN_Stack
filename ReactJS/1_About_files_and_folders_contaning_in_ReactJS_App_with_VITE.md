**node\_modules** – Contains all the libraries installed for the project.

**public** – Stores files like images, videos, and icons that don't change.

**src** – Contains all the source code of the React application.

**assets** – Stores images, fonts, icons, and other resources used in the project.

**App.jsx** – The main component where we design the application's user interface.

**App.css** – Contains the CSS styles for the App component.

**index.css** – Contains CSS styles that apply to the whole application.

**main.jsx** – The starting point of the React application.

**.gitignore** – Tells Git which files and folders should not be tracked.

**.oxlintrc.json** – Contains rules to maintain clean and consistent code.

**index.html** – The main HTML page where the React application is displayed.

**package.json** – Contains project information, dependencies, and npm commands.

**package-lock.json** – Keeps track of the exact versions of installed packages.

**README.md** – Contains information and instructions about the project.

**vite.config.js** – Contains configuration settings for the Vite development server.
