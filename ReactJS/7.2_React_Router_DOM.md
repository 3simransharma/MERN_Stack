# React Router DOM --- Concepts from NavLink Onward

## 5. NavLink

`NavLink` is similar to `Link`, but it provides additional information
about whether the current link is **active**.

### Import

``` jsx
import { NavLink } from "react-router-dom";
```

### Basic Syntax

``` jsx
<NavLink to="/about">
  About
</NavLink>
```

It works like `Link`, but `NavLink` can detect whether `/about` is
currently the active route.

### Why use NavLink?

Suppose you have:

``` text
Home | About | Contact
```

When the user is on `/about`, you may want the About link to have a
different style.

`NavLink` makes this easy.

### Active State

`NavLink` provides an `isActive` value.

``` jsx
<NavLink
  to="/about"
  className={({ isActive }) =>
    isActive ? "active" : ""
  }
>
  About
</NavLink>
```

If the current URL is `/about`:

``` text
isActive = true
```

Otherwise:

``` text
isActive = false
```

### Example

``` jsx
function Navbar() {
  return (
    <nav>

      <NavLink
        to="/"
        className={({ isActive }) =>
          isActive ? "active" : ""
        }
      >
        Home
      </NavLink>

      <NavLink
        to="/about"
        className={({ isActive }) =>
          isActive ? "active" : ""
        }
      >
        About
      </NavLink>

      <NavLink
        to="/contact"
        className={({ isActive }) =>
          isActive ? "active" : ""
        }
      >
        Contact
      </NavLink>

    </nav>
  );
}
```

CSS:

``` css
.active {
  color: red;
  font-weight: bold;
}
```

### Link vs NavLink

| `Link` | `NavLink` |
|---|---|
| Used for navigation between pages | Used for navigation between pages |
| Provides **simple navigation** | Provides **navigation with active-state support** |
| Does not directly provide active-state information | Provides the **`isActive`** property |
| Commonly used for general links | Commonly used in **navigation bars and sidebars** |
| Best when active styling is not required | Best when the **currently active link needs to be highlighted** |

<br>

**Remember:**

> `Link` = Go somewhere\
> `NavLink` = Go somewhere + know if you're currently there

# 6. useNavigate()

`useNavigate()` is a **React Router hook** that allows JavaScript code
to navigate to another route.

### Import

``` jsx
import { useNavigate } from "react-router-dom";
```

### Basic Example

``` jsx
function Login() {

  const navigate = useNavigate();

  function handleLogin() {
    navigate("/dashboard");
  }

  return (
    <button onClick={handleLogin}>
      Login
    </button>
  );
}
```

### How it works

``` text
/login
   ↓
handleLogin()
   ↓
navigate("/dashboard")
   ↓
/dashboard
```

### When to use it?

Use `useNavigate()` when navigation happens because of some logic or
event.

Examples:

-   Successful login
-   Form submission
-   Button click
-   Logout
-   After completing an operation

### Going Back

``` jsx
navigate(-1);
```

### Going Forward

``` jsx
navigate(1);
```

**Remember:**

> `useNavigate()` = Navigate through JavaScript

# 7. Dynamic Routes

A **dynamic route** is a route where part of the URL can change.

Example:

``` text
/products/101
/products/102
/products/103
```

Instead of creating a separate route for every product, create one
dynamic route:

``` jsx
<Route
  path="/products/:id"
  element={<Product />}
/>
```

Here:

``` text
:id
```

is a **dynamic parameter**.

### Why use Dynamic Routes?

Suppose an e-commerce website has thousands of products.

You don't want:

``` jsx
<Route path="/products/1" ... />
<Route path="/products/2" ... />
<Route path="/products/3" ... />
```

Instead:

``` jsx
<Route
  path="/products/:id"
  element={<Product />}
/>
```

One route can handle all products.

# 8. useParams()

`useParams()` is used to **read dynamic values from the URL**.

### Route

``` jsx
<Route
  path="/products/:id"
  element={<Product />}
/>
```

### Component

``` jsx
import { useParams } from "react-router-dom";

function Product() {

  const { id } = useParams();

  return (
    <h1>Product ID: {id}</h1>
  );
}
```

If the URL is:

``` text
/products/101
```

then:

``` text
id = "101"
```

If the URL is:

``` text
/products/500
```

then:

``` text
id = "500"
```

### Flow

``` text
/products/101
       ↓
:id = 101
       ↓
useParams()
       ↓
id = "101"
```

### Multiple Parameters

You can have multiple dynamic parameters:

``` jsx
<Route
  path="/student/:studentId/course/:courseId"
  element={<StudentCourse />}
/>
```

URL:

``` text
/student/25/course/101
```

Component:

``` jsx
const {
  studentId,
  courseId
} = useParams();
```

Result:

``` text
studentId = "25"
courseId = "101"
```

**Remember:**

> `useParams()` = Read dynamic values from the URL

# 9. Nested Routes

Nested routes are routes **inside another route**.

Suppose you have a dashboard:

``` text
/dashboard
/dashboard/profile
/dashboard/settings
/dashboard/orders
```

You can write:

``` jsx
<Route
  path="/dashboard"
  element={<Dashboard />}
>
  <Route
    path="profile"
    element={<Profile />}
  />

  <Route
    path="settings"
    element={<Settings />}
  />

  <Route
    path="orders"
    element={<Orders />}
  />
</Route>
```

Here:

-   `/dashboard` → Parent route
-   `profile` → Child route
-   `settings` → Child route
-   `orders` → Child route

### Important

Child paths are usually written without the leading `/`:

``` jsx
path="profile"
```

not:

``` jsx
path="/profile"
```

### Structure

``` text
Dashboard
   ├── Profile
   ├── Settings
   └── Orders
```

**Remember:**

> Nested Routes = Routes inside another route

# 10. Outlet

When using nested routes, we need to tell React Router:

> "Where should the child component appear?"

That's what `Outlet` does.

### Import

``` jsx
import { Outlet } from "react-router-dom";
```

### Example

``` jsx
function Dashboard() {
  return (
    <div>

      <h1>Dashboard</h1>

      <Outlet />

    </div>
  );
}
```

If the URL is:

``` text
/dashboard/profile
```

React Router renders:

``` text
Dashboard
   ↓
Outlet
   ↓
Profile
```

So `<Outlet />` acts as a **placeholder for child routes**.

### Visual Example

``` text
Dashboard
    |
    └── Outlet
          |
          ├── Profile
          ├── Settings
          └── Orders
```

**Remember:**

> `Outlet` = Place where the child route is displayed

# 11. Navigate

`Navigate` is used to **redirect a user to another route**.

### Import

``` jsx
import { Navigate } from "react-router-dom";
```

### Example

``` jsx
<Route
  path="/old"
  element={<Navigate to="/new" />}
/>
```

If the user visits:

``` text
/old
```

they are redirected to:

``` text
/new
```

### Common uses

-   Redirecting after login
-   Redirecting logged-out users
-   Replacing old routes
-   Sending users to a default page

**Remember:**

> `Navigate` = Redirect

# 12. Protected Routes

Protected routes are used when a page should only be accessible to
authenticated users.

For example:

``` text
/login
/dashboard
/profile
```

You may want only logged-in users to access `/dashboard`.

### Basic Concept

``` text
User visits /dashboard
          ↓
     Logged in?
       ↙    ↘
     YES     NO
      ↓       ↓
 Dashboard   Login
```

### Example

``` jsx
function ProtectedRoute({ children }) {

  const isLoggedIn = true;

  if (!isLoggedIn) {
    return <Navigate to="/login" />;
  }

  return children;
}
```

Then:

``` jsx
<Route
  path="/dashboard"
  element={
    <ProtectedRoute>
      <Dashboard />
    </ProtectedRoute>
  }
/>
```

### In a real MERN application

The `isLoggedIn` value would normally come from authentication state,
such as:

-   JWT token
-   Context API
-   Redux
-   Authentication state

This pattern is commonly used for:

-   Admin dashboards
-   User profiles
-   Account pages
-   Private application pages

**Remember:**

> Protected Route = Allow access only when the user is authenticated
