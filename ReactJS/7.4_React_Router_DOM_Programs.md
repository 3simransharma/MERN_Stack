# React Router DOM Examples

React Router DOM allows a React application to have **multiple URLs and
views** while behaving like a Single Page Application (SPA).

------------------------------------------------------------------------

# Level 1 --- Basic Routing

## Example 1: Three Simple Pages

``` jsx
import {
  BrowserRouter,
  Routes,
  Route
} from "react-router-dom";

function Home() {
  return <h1>Home</h1>;
}

function About() {
  return <h1>About</h1>;
}

function Contact() {
  return <h1>Contact</h1>;
}

function App() {
  return (
    <BrowserRouter>

      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
        <Route path="/contact" element={<Contact />} />
      </Routes>

    </BrowserRouter>
  );
}

export default App;
```

### URL structure

``` text
/          → Home
/about     → About
/contact   → Contact
```

# Level 2 --- Navigation Using Link

Instead of manually typing URLs, give the user navigation links.

``` jsx
import {
  BrowserRouter,
  Routes,
  Route,
  Link
} from "react-router-dom";

function Home() {
  return <h1>Home Page</h1>;
}

function About() {
  return <h1>About Page</h1>;
}

function Contact() {
  return <h1>Contact Page</h1>;
}

function App() {
  return (
    <BrowserRouter>

      <nav>
        <Link to="/">Home</Link>
        <Link to="/about">About</Link>
        <Link to="/contact">Contact</Link>
      </nav>

      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
        <Route path="/contact" element={<Contact />} />
      </Routes>

    </BrowserRouter>
  );
}
```

### Flow

``` text
Click About
    ↓
<Link to="/about">
    ↓
URL changes
    ↓
Route matches /about
    ↓
<About /> renders
```

# Level 4 --- useNavigate()

`useNavigate()` allows JavaScript code to navigate to another route.

## Example: Navigate After Login

``` jsx
import { useNavigate } from "react-router-dom";

function Login() {

  const navigate = useNavigate();

  function handleLogin() {

    console.log("Login successful");

    navigate("/dashboard");
  }

  return (
    <button onClick={handleLogin}>
      Login
    </button>
  );
}
```

Flow:

``` text
Login
 ↓
handleLogin()
 ↓
navigate("/dashboard")
 ↓
Dashboard
```

## Example: Navigate After Form Submission

``` jsx
function Register() {

  const navigate = useNavigate();

  function handleSubmit(e) {

    e.preventDefault();

    // Save user

    navigate("/success");
  }

  return (
    <form onSubmit={handleSubmit}>

      <input placeholder="Name" />

      <button type="submit">
        Register
      </button>

    </form>
  );
}
```

# Level 5 --- Dynamic Routes

Imagine an e-commerce website.

You have:

``` text
/products/1
/products/2
/products/3
/products/4
```

Create one route:

``` jsx
<Route
  path="/products/:id"
  element={<Product />}
/>
```

Then:

``` jsx
function Product() {

  const { id } = useParams();

  return (
    <h1>
      Product ID: {id}
    </h1>
  );
}
```

Now:

``` text
/products/101
```

gives:

``` text
Product ID: 101
```

And:

``` text
/products/500
```

gives:

``` text
Product ID: 500
```

# Level 8 --- Nested Routes

This is very useful for dashboards.

Suppose:

``` text
/dashboard
/dashboard/profile
/dashboard/settings
/dashboard/orders
```

Routes:

``` jsx
<Route
  path="/dashboard"
  element={<Dashboard />}
>

  <Route
    path="profile"
    element={<Profile />}
  />

  <Route
    path="settings"
    element={<Settings />}
  />

  <Route
    path="orders"
    element={<Orders />}
  />

</Route>
```

Parent component:

``` jsx
function Dashboard() {

  return (
    <div>

      <h1>Dashboard</h1>

      <Outlet />

    </div>
  );
}
```

If URL is:

``` text
/dashboard/profile
```

React renders:

``` text
Dashboard

Profile
```

because:

``` jsx
<Outlet />
```

is replaced by:

``` jsx
<Profile />
```

# Level 13 --- Protected Route

Now let's make something closer to a MERN application.

Suppose:

``` text
/login
/dashboard
```

Only logged-in users should access Dashboard.

Create:

``` jsx
function ProtectedRoute({ children }) {

  const isLoggedIn = true;

  if (!isLoggedIn) {
    return <Navigate to="/login" />;
  }

  return children;
}
```

Then:

``` jsx
<Route
  path="/dashboard"
  element={
    <ProtectedRoute>
      <Dashboard />
    </ProtectedRoute>
  }
/>
```

### Flow

``` text
User → /dashboard
          ↓
   ProtectedRoute
          ↓
    Is logged in?
       /     \
     YES      NO
      ↓        ↓
Dashboard     Login
```

# Level 14 --- Protected Route with Outlet

For a larger application, you can protect an entire group of routes.

``` jsx
function ProtectedLayout() {

  const isLoggedIn = true;

  if (!isLoggedIn) {
    return <Navigate to="/login" />;
  }

  return <Outlet />;
}
```

Routes:

``` jsx
<Route element={<ProtectedLayout />}>

  <Route
    path="/dashboard"
    element={<Dashboard />}
  />

  <Route
    path="/profile"
    element={<Profile />}
  />

  <Route
    path="/settings"
    element={<Settings />}
  />

</Route>
```

Now all three pages are protected.

This is a very useful pattern.

# Level 15 --- Query Parameters

Suppose you have:

``` text
/products?category=laptop
```

You can read `category` using `useSearchParams()`.

``` jsx
import {
  useSearchParams
} from "react-router-dom";

function Products() {

  const [searchParams] =
    useSearchParams();

  const category =
    searchParams.get("category");

  return (
    <h1>
      Category: {category}
    </h1>
  );
}
```

Result:

``` text
Category: laptop
```

# Level 17 --- Change Query Parameters

You can also modify them.

``` jsx
const [searchParams, setSearchParams] =
  useSearchParams();

  setSearchParams({
    category: "laptop",
    sort: "price"
  });

}
```

The URL becomes:

``` text

```

This is useful for:

-   Search
-   Filtering
-   Sorting
-   Pagination

# Level 18 --- useLocation()

`useLocation()` gives information about the current URL.

``` jsx
import {
  useLocation
} from "react-router-dom";

function Page() {

  const location = useLocation();

  console.log(location);

  return <h1>Current Page</h1>;
}
```

You can access:

``` jsx
location.pathname
location.search
location.hash
location.state
```

For example:

``` text
/products?category=laptop
```

gives approximately:

``` text
pathname → /products
search   → ?category=laptop
```

# Level 19 --- Passing State During Navigation

You can send temporary state while navigating.

``` jsx
<Link
  to="/profile"
  state={{
    username: "Simran"
  }}
>
  Profile
</Link>
```

Then retrieve it:

``` jsx
import { useLocation } from "react-router-dom";

function Profile() {

  const location = useLocation();

  console.log(location.state);

  return (
    <h1>
      {location.state?.username}
    </h1>
  );
}
```

This can be useful when passing information between pages without
putting it directly in the URL.

# Level 20 --- Combining Dynamic Route + API

This is where React Router becomes very useful in a MERN application.

Suppose:

``` text
/products/101
```

Route:

``` jsx
<Route
  path="/products/:id"
  element={<Product />}
/>
```

Component:

``` jsx
function Product() {

  const { id } = useParams();

  const [product, setProduct] =
    useState(null);

  useEffect(() => {

    fetch(`/api/products/${id}`)
      .then(res => res.json())
      .then(data => setProduct(data));

  }, [id]);

  if (!product) {
    return <p>Loading...</p>;
  }

  return (
    <div>

      <h1>{product.name}</h1>

      <p>
        ₹{product.price}
      </p>

    </div>
  );
}
```

### Flow

``` text
/products/101
       ↓
useParams()
       ↓
id = 101
       ↓
GET /api/products/101
       ↓
Express/Node.js
       ↓
MongoDB
       ↓
Product data
       ↓
React displays product
```

This is a very common MERN pattern.

# Level 21 --- Complete example

A realistic application might look like:

``` jsx
function App() {

  return (
    <BrowserRouter>

      <Routes>

        {/* Public */}
        <Route
          path="/"
          element={<Home />}
        />

        <Route
          path="/login"
          element={<Login />}
        />

        <Route
          path="/products"
          element={<Products />}
        />

        {/* Dynamic */}
        <Route
          path="/products/:id"
          element={<Product />}
        />

        {/* Protected */}
        <Route element={<ProtectedLayout />}>

          <Route
            path="/dashboard"
            element={<Dashboard />}
          />

          <Route
            path="/profile"
            element={<Profile />}
          />

        </Route>

        {/* 404 */}
        <Route
          path="*"
          element={<NotFound />}
        />

      </Routes>

    </BrowserRouter>
  );
}
```

This combines:

-   `BrowserRouter`
-   `Routes`
-   `Route`
-   Dynamic routes
-   Protected routes
-   `Outlet`
-   404 route

# Important Concept: Link vs useNavigate vs Navigate

This is something you should definitely remember.

## Link

User clicks it.

``` jsx
<Link to="/about">
  About
</Link>
```

### Meaning

``` text
Link
 ↓
User navigation
```

------------------------------------------------------------------------

## useNavigate

Your JavaScript code decides to navigate.

``` jsx
navigate("/dashboard");
```

### Meaning

``` text
useNavigate()
 ↓
Programmatic navigation
```

------------------------------------------------------------------------

## Navigate

A component performs a redirect.

``` jsx
<Navigate to="/login" />
```

### Meaning

``` text
Navigate
 ↓
Redirect
```

# Most Importantly,

You should be able to explain these without looking at notes:

**`BrowserRouter → Routes → Route → Link → NavLink → useNavigate → useParams → Dynamic Routes → Nested Routes → Outlet → Navigate → Protected Routes → useSearchParams → useLocation`**

The core idea:

> **URL determines the Route → Route determines the Component →
> `Link`/`NavLink` changes the URL → hooks such as `useParams` and
> `useLocation` let the component read URL information → `useNavigate`
> lets code change the URL.**
