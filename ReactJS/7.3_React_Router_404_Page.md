# How to Add a 404 Page in React Router

## What is a 404 Page?

A **404 Page** or **Page Not Found Page** is displayed when the user
tries to open a route that does not exist in the application.

For example, if the application has `/`, `/about`, and `/contact`, but
the user opens `/student`, a 404 page can be displayed.

------------------------------------------------------------------------

## Step 1: Create a `NotFound` Component

``` jsx
import { Link } from "react-router-dom";

function NotFound() {
    return (
        <>
            <h1>404</h1>
            <h2>Page Not Found</h2>
            <p>The page you are looking for does not exist.</p>

            <Link to="/">
                Go to Home
            </Link>
        </>
    );
}

export default NotFound;
```

The `Link` allows the user to return to the Home page.

------------------------------------------------------------------------

## Step 2: Add the 404 Route

Add a route with `path="*"`.

``` jsx
import { Routes, Route } from "react-router-dom";

function App() {
    return (
        <Routes>
            <Route path="/" element={<Home />} />
            <Route path="/about" element={<About />} />
            <Route path="/contact" element={<Contact />} />

            <Route path="*" element={<NotFound />} />
        </Routes>
    );
}

export default App;
```

------------------------------------------------------------------------

## What Does `path="*"` Mean?

The `*` is called a **wildcard**.

``` jsx
<Route path="*" element={<NotFound />} />
```

It means that if the entered URL does not match any defined route, React
Router displays the `NotFound` component.

### Example

``` text
/          → Home
/about     → About
/contact   → Contact
```

If the user enters `/about`, the **About** component is displayed.

If the user enters `/student`, there is no matching route, so the **404
Page** is displayed.

------------------------------------------------------------------------

## Expected Output

``` text
404

Page Not Found

The page you are looking for does not exist.

Go to Home
```

------------------------------------------------------------------------

## Important Point

To create a 404 Page in React Router, remember:

``` jsx
<Route path="*" element={<NotFound />} />
```

`*` acts as a **wildcard route** and handles URLs that do not match any
of the routes defined in the application.
